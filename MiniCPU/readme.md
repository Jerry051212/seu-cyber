# 计算机组成原理实验（Experiment of Principles of Computer Organization）：MiniCPU
用quartus实现的简易CPU，包括算术逻辑单元（Arithmetic Logic Unit，ALU），内存（MEM），寄存器组（Register block）和控制器（Contoller），最终合成一个简单的CPU模型，可以实现Load，加减法和JNZ指令。
The MiniCPU implemented with quartus includes an arithmetic logic unit (ALU), memory (MEM), register block, and controller (Contoller), ultimately synthesizing a simple CPU model that can implement load, addition and subtraction, and JNZ instructions.
