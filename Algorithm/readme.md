# 算法分析（Algorithm Analysis）实验
实验一：铺砖问题：编写一个程序，在16Ö16的方格中，有任意一个空格，输出在剩余
格子中铺”L”型地砖的方案

Tile Laying Problem: Write a program that, given a 16x16 grid with any empty cell, outputs the possible tile layout for laying an "L" shape in the remaining cells.

实验二：焊接铁罐问题时间复杂度：n个铁管具有重量，被按序存放在w[i]，1≤i≤n。这些铁管将根据它们的顺
序，被焊接成一个大的铁管，每个时间任意两个相邻的铁管可以被选中来进行焊接。焊
接的代价是焊接的铁管中的重量较大的铁管的重量。a）设计一个动态规划算法去发现最优的焊接顺序，使得整个代价最小和确立迭代
关系。b）将设计的算法应用到一个具体的实例中，去发现最优焊接顺序和其相应的焊接
总代价，该实例具有5个钢管，w[1]=6，w[2]=2，w[3]=7，w[4]=5，w[5]=8。请给出详
细的解决过程。

Welding Iron Can Problem Time Complexity: n iron pipes, each with weight, are stored in w[i] in sequence, 1≤i≤n. These iron pipes will be welded into a larger iron pipe according to their order. At any given time, any two adjacent iron pipes can be selected for welding. The cost of welding is the weight of the heavier iron pipe among the welded pipes. a) Design a dynamic programming algorithm to find the optimal welding order that minimizes the total cost and establishes the iterative relationship. b) Apply the designed algorithm to a specific instance to find the optimal welding order and its corresponding total welding cost. This instance has 5 steel pipes, w[1]=6, w[2]=2, w[3]=7, w[4]=5, w[5]=8. Please provide a detailed solution process.
